# The search field's box is reserved from first paint, and its focus ring is solid

`.strand-search-field` declares every dimension (an inline size of `--strand-search-field-inline-size`, defaulting to `min(300px, 100%)`; a 36px height stated directly because the spacing scale has no rung there; 44px under `@media (pointer: coarse)`), so a server-rendered field occupies its final geometry in the first frame; its first consumer puts it in a fixed header, where a late-appearing box pushes every pixel of the page. `__input` carries `min-inline-size: 0` so a flex item's automatic minimum cannot push the field past its declared box, and its placeholder and icon are gray-500 (the text tier) with no UA opacity. The focused state is `:focus-within` (a text field accepting keystrokes must show it however focus arrived), and the ring is `2px solid --strand-blue-primary`, not the 10%-alpha `--strand-focus-ring` token: at that alpha the ring blends to about 1.1:1 and is not an indicator (SC 1.4.11 wants 3:1). The field supplies its own clear control (WebKit's proprietary one is hidden), absent rather than invisible when the field is empty. It is not `.strand-search-bar`, the overlay that floats on an instrument viewport.
