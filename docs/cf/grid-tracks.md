# A layout primitive never clips, and every fixed track is `minmax(0, 1fr)`

Design language 10.4 gives two remedies for two kinds of thing: containers with a padded surface clip; layout primitives set `min-width: 0` on their children so items shrink instead of overflowing. `.strand-grid`, `.strand-ref-shell`, `.strand-stat-strip` and `.strand-calendar-grid` are the second kind, so they never clip (a clip on a grid cut off every child's hover lift and elevation at the grid's edge and hid the real defect). The real defect is a bare `1fr`, which floors a track at its content's min-content width, so one long unbroken string widens the whole grid past its container and pushes a rail off screen; every fixed track is `minmax(0, 1fr)`, and grid children carry `min-width: 0`. `--sidebar` is a fixed rail beside a flexible main track (rail first in the markup, because the regions stack in source order below the md breakpoint and a filter met after its results is already scrolled past); `--split` mirrors it with the flexible track first and the fixed panel's width in `--strand-grid-split-panel`. A consumer that needs a clipped box wants a Card or a FeatureSurface.

Where: `Grid.css`, `LabShell.css`, `StatStrip.css`, `CalendarGrid.css` under `packages/strand-ui/src/components/`
