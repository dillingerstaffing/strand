# Reserve stacks both layers in one grid cell, and only the consumer may declare the region empty

`.strand-reserve` places `__placeholder` and `__content` in the same grid cell, so the swap cannot move layout: the two are always in the same position and only opacity differs, and the region sizes to the taller layer. The floors are per-breakpoint tokens (`--strand-reserve-h` and its `-md`, `-lg` steps, each falling back to the one below); unset means no floor, because a placeholder that already matches its content needs none. The cross-fade is opacity with `visibility` riding the same transition, so the hidden layer leaves the accessibility tree and stops taking pointer events. `data-strand-reserve="empty"` takes the placeholder out of flow, because `visibility: hidden` preserves layout and a region whose content resolves to nothing would otherwise stay at the placeholder's height forever; it is a state the consumer declares, never an automatic collapse, because collapsing when content is merely shorter than the placeholder would silently convert a mis-sized reservation into a late shift, which is the exact bug the primitive exists to surface. No attribute at all resolves to ready. That attribute is the whole runtime.
